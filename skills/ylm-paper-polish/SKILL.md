# YLM 文章综合润色

协调四个可独立使用的专用 skills。只负责选任务、统一授权、协调候选修改和验收，不另写一套与专用规则竞争的润色指南。

## 选择模块

| 实际需求 | 专用 skill | 修改责任 |
| --- | --- | --- |
| 语法、措辞、清晰度、简洁性 | `ylm-paper-language` | 语言表达，保持段落职责和论证关系 |
| 套话、机械连接、空泛包装、回复口吻 | `ylm-paper-deai` | 去模板化表达；深层结构问题只标记 |
| 句段安排、信息顺序、论述衔接、审稿补充位置 | `ylm-paper-flow` | 保持技术含义的段落重组 |
| 术语、符号、跨节主张、引用、格式、编译 | `ylm-paper-check` | 一致性诊断及明确获批的结构修复 |

按本次需求读取所选模块的 `SKILL.md` 及其适用参考文件。解析位置时先使用会话技能目录中的实际路径；本套件同级安装时也可使用相对于本文件的 `../ylm-paper-language/SKILL.md` 等同级路径。不要硬编码用户主目录，不调用旧名称，不预先读取全部模块。

明确要求完整综合润色时评估四项需求；只请求其中几项时限于这些项。局部片段的一致性检查只核对可见不变量，不能宣称全文或编译覆盖。缺少所需模块时说明未覆盖任务并继续可独立完成的部分，不让另一模块假装已完成缺失能力。

## 统一流程

1. **确定范围和基线。** 识别文本／工程、语言、主文件、目标区域和既有差异；建立可比较的源文件基线。全文先理解章节和关键主张，再按完整语义单元编辑。各角色使用同一目标版本。
2. **诊断与方案。** 在所选能力范围内完整检查。语言问题可以独立进入方案，不要求必须由去痕迹或一致性审查先发现。合并相同根因，记录位置、证据、影响、修改方向和技术风险；不维护复杂状态机。
3. **一次确认。** 默认一次提交诊断、修改边界及代表性候选改法，等待用户确认后编辑。只审查／只计划时不改文件；用户当次明确要求直接改或已批准此范围时连续完成。仅调用集成入口本身不视为跳过默认确认。
4. **协调修改。** 先做获批的信息组织调整，再在最新文本上处理语言与去痕迹，最后做一致性检查；无相应修改的阶段跳过。每次候选须注明基线与目标片段，后续模块不将旧版本候选机械覆盖到新文本。
5. **检查并交付。** 对照原文、修改稿和差异，检查语义、LaTeX、跨模块回归及实际解决的问题。默认一轮编辑加一轮针对性修正；不因主观措辞偏好继续循环。

专用模块内部不向用户重复确认。遇到语义或作者意图缺失时保留有关片段，集中提问，其他已批准部分继续。确认期间用户改了文本，先复核变化及有关候选，不覆盖新内容。

## 编辑边界

- 默认可以保持技术含义地调整句序、合并拆分段落；章节重排或跨节搬移仅提建议，明确获批后才实施。
- 科学含义优先于风格。保护假设、数值、量词、否定、适用条件、比较对象、证据归属、结论强度、最优性保证及理论／经验区别。
- 默认保护 LaTeX 公式、宏、环境、标签、引用和绑定关系；明确的结构修复须列入获批方案。不能为完成润色而修造数学结果或添加未知证据。
- 用户指定保留的主张不能因被评为“不够自然”就删改。无法安全修复的问题保留并报告。

## 学术表达的可读性

综合润色以专业、自然、易读为默认语域。严谨性来自概念、条件和论证的准确；清楚直接的句式可以用于学术文章。选择同等准确而更容易理解的表达，无需为了学术感堆叠长句、从句、名词化结构或生僻词，也不把正文改成随意口语。

语言与去痕迹模块共同遵守这一目标。去痕迹模块按具体阅读负担调整句式，必要时在同一段内拆分长句；只有涉及段落功能或信息位置变化时才交给 flow。将可读性目标传给后续编辑和复查角色，避免后续模块又把已清楚的表达复杂化。

拆句后逐一核对条件、量词、否定、必要／充分关系、比较范围及引用仍绑定原主张。保留有效的复杂句，不设置统一句长目标，不追求机械短句化；读者负担的改善不能以丢失技术限定为代价。

## 单智能体与多智能体

子 skill 是能力模块，不意味着必须创建一个智能体。局部普通任务由协调者读取所选规则并处理。

全文或涉及多处技术主张的修订，在委派工具可用时使用协调者加一名独立回归审查者；额外专家只在具体冲突或可独立分工的工作确有价值时启用。委派时读取 [协作契约](references/coordination.md)。审查者只提发现／候选，不改共享源文件。没有委派能力则顺序完成并如实说明缺少独立复查。

协调者是唯一的论文源文件编辑者，并默认拥有每个目标版本的编译任务。可以把编译明确委派给检查角色，但不能同时自己再运行同一检查。优先项目既有构建方式和实际引擎，不固定强制 pdfLaTeX。

## 完成标准

- 获批修改通过语义与 LaTeX 差异检查，没有新引入的阻断／重大问题；不声称这等于数学正确性证明。
- 原有重大问题已修复，或明确列为需要作者判断、范围外或作者决定保留；不能用这些例外伪装成全部通过。
- 修改仅涉及授权区域，编译状态与基线可比较；无法执行的检查单独说明。
- 去痕迹修改具有原文证据，未引入虚构具体信息、新模板或必要限定缺失。
- 句式调整提高了可读性并保持学术精确性；拆句未改变条件和引用的作用域，后续处理未无理由地重新复杂化表达。

交付结果、代表性对照、实际调用模块与检查覆盖、关键保留信息以及遗留问题。无需展示冗长内部讨论或所有候选。普通审查判断与机械检查证据分开表述。
